# Instalação manual

Este guia instala o pacote sem usar o Milton Fretes Launcher.

## Passo a passo

1. Feche o Euro Truck Simulator 2.
2. Baixe o pacote [milton-fretes.scs da release mais recente](https://github.com/andreltcarvalho/milton-fretes-ets-mod/releases/latest/download/milton-fretes.scs).
3. Abra a pasta de mods do ETS2. O caminho padrão é:

   ```text
   Documentos\Euro Truck Simulator 2\mod
   ```

   Se o jogo usa outra pasta de dados, localize a pasta `mod` dentro dela. Se ela ainda não existir, crie-a.

4. Renomeie o arquivo baixado para **`Milton Fretes skins.scs`** e copie-o para a pasta `mod`.
5. Se já houver um `Milton Fretes skins.scs`, mova a cópia antiga para outra pasta antes de copiar a nova. Assim você mantém um backup e evita duas versões do mesmo mod na pasta `mod`.
6. Abra o ETS2, escolha o perfil e entre no **Gerenciador de Mods**.
7. Ative **Milton Fretes skins**, confirme a mudança e carregue o perfil.

## Comboio

Para jogar no Comboio, todos devem instalar a mesma versão do pacote, usar o nome **`Milton Fretes skins.scs`** e ativar o mod no perfil. A versão e as mudanças estão na [release mais recente](https://github.com/andreltcarvalho/milton-fretes-ets-mod/releases/latest).

## Se o mod não aparecer

- Confira se o arquivo termina em `.scs` — e não em `.scs.zip`.
- Confirme que ele está diretamente dentro da pasta `mod` correta, sem uma subpasta extra.
- No Gerenciador de Mods, verifique se **Milton Fretes skins** está ativo no perfil que você abriu.
- Se usa uma pasta de dados personalizada, confirme que copiou o arquivo para a pasta desse perfil.
